## Learning Outcomes

Upon completion of ITAI 1378, students will be able to:

1. Define key terminology in computer vision, image processing, and visual AI technologies.
2. Explain the computer vision pipeline and its role within broader AI-robotics workflows.
3. Implement image preprocessing, feature extraction, and deep learning models using Python libraries and frameworks.
4. Interpret visual representations, model architectures, and detection/segmentation outputs to gain analytical insight.
5. Critique biases, privacy concerns, and societal impacts of visual AI technologies, proposing mitigation strategies.
6. Construct and present an end-to-end computer vision system leveraging modern architectures and frameworks[cite: 4].

## Learning Objectives

* Summarize the historical evolution, foundational concepts, and industrial impact of computer vision in AI and robotics.
* Differentiate among image processing techniques, deep learning architectures, and their appropriate use cases.
* Apply machine learning and deep learning methods to construct end-to-end visual processing pipelines.
* Analyze visual features and representations to extract meaningful information from images and video.
* Evaluate the effectiveness, fairness, and ethical implications of computer vision systems using quantitative metrics and critical reflection.
* Design and create a functional computer vision application that integrates preprocessing, modeling, and deployment best practices[cite: 4].
