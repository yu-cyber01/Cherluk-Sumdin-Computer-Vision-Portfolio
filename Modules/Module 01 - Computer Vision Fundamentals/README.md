# Lab 01: Exploring Real-World Applications of Computer Vision

**Course:** ITAI 1378  
**Assignment:** L01 - Exploring Real-World Applications of Computer Vision  

---

## 📌 Overview

This project explores and analyzes a real-world application of computer vision to understand its practical uses, core enabling technologies, and broader societal impact.

---

## 🎯 Objectives & Guidelines

1. **Select a Computer Vision Application**
   * Choose a common real-world application (e.g., facial recognition, autonomous vehicles, medical image analysis, retail checkout systems).
2. **Research**
   * **How it works:** Core hardware and software components.
   * **Role of Computer Vision:** How CV solves the specific problem or enhances system functionality.
3. **Analysis (1–2 Pages)**
   * **Description of Application:** What it does, target users, and the real-world problem it addresses.
   * **Technology Behind It:** Cameras/sensors, image processing techniques, and AI decision-making models.
   * **Benefits & Challenges:** Advantages alongside technical, ethical, or practical limitations with concrete examples.
4. **Reflection**
   * Future technological developments.
   * Positive and negative impacts on society.
