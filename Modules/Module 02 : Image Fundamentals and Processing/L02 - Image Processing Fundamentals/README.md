## 📚 Lab Structure & Requirements

### Part 1: Digital Image Fundamentals (10 min)
* **Tasks:** Load/analyze test image, inspect matrix properties (shape, data type, range), separate RGB channels, compare grayscale conversion techniques.
* **Deliverables:** Executed code cells, matrix property analysis, and grayscale method comparison.

### Part 2: Basic Image Operations (10 min)
* **Tasks:** Build brightness/contrast adjustments from scratch, apply convolution kernels (blur, sharp, edge detect), explore point vs. neighborhood operations.
* **Deliverables:** Custom mathematical functions, applied filters, visual comparison.

### Part 3: Advanced Processing Techniques (10 min)
* **Tasks:** Analyze histograms, perform histogram equalization/CLAHE, apply geometric transformations (scaling, rotation, translation).
* **Deliverables:** Histograms, geometric transforms, before/after statistical comparisons.

### Part 4: Creative Exploration (5 min)
* **Tasks:** Combine multiple operations to build at least one custom artistic filter/pipeline.
* **Deliverables:** Visual output and documented creative pipeline.

### Part 5: AI Connection (5 min)
* **Tasks:** Run the AI simulation code and connect traditional CV operations to AI tools (such as Nano Banana).
* **Deliverables:** Completed simulation analysis and AI-traditional connection response.
